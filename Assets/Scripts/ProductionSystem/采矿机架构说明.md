# 采矿机架构说明

## 1. 架构设计

采矿机采用 **父子层级结构**：

```
MiningMachine (父物体 - 采矿机控制器)
├── 挂载组件：MiningMachine.cs + PowerConsumer
── 参数：powerConsumption = 10W
│
├── Body (子物体 - 采矿机本体)
│   └── 挂载组件：BuildingBase
│       ├── 参数：maxHealth = 100
│       └── 功能：血量管理、碰撞检测
│
└── CollectionArea (子物体 - 采矿区域)
    ── 挂载组件：MiningCollector
        ├── 参数：miningAmount = 1, collectionWidth = 2, collectionHeight = 2
        └── 功能：矿石检测、采集、电力检查
```

---

## 2. 组件职责

### 2.1 MiningMachine（父物体）
- **核心职责**：电力管理、组件协调
- **必需组件**：
  - `MiningMachine.cs` - 控制器脚本
  - `PowerConsumer` - 电力消费者（自动添加）
- **可选组件**：无

### 2.2 Body（子物体 - 本体）
- **核心职责**：血量管理、物理碰撞
- **必需组件**：
  - `BuildingBase.cs` - 建筑基类
  - `Collider2D` - 碰撞体（BuildingBase 自动添加）
- **可选组件**：无

### 2.3 CollectionArea（子物体 - 采集区域）
- **核心职责**：矿石检测、采集
- **必需组件**：
  - `MiningCollector.cs` - 采集器脚本
  - `Collider2D` - 触发器（MiningCollector 自动添加）
- **可选组件**：无

## 3. Unity 预制体设置步骤

### 3.1 创建父物体

1. 创建空物体，命名为 `MiningMachine`
2. 添加组件：
   - `MiningMachine` 脚本
   - `PowerConsumer` 脚本
3. 设置参数：
   - **MiningMachine.powerConsumption** = 10
   - **PowerConsumer.powerInput** = 10
   - **PowerConsumer.priority** = 5

### 3.2 创建本体子物体

1. 在 `MiningMachine` 下创建空物体，命名为 `Body`
2. 添加组件：
   - `BuildingBase` 脚本
   - `BoxCollider2D` 或 `CircleCollider2D`
3. 设置参数：
   - **BuildingBase.maxHealth** = 100
   - **Collider2D.isTrigger** = true（可选，如果需要碰撞扣血）

### 3.3 创建采集区域子物体

1. 在 `MiningMachine` 下创建空物体，命名为 `CollectionArea`
2. 添加组件：
   - `MiningCollector` 脚本
   - `BoxCollider2D`
3. 设置参数：
   - **MiningCollector.miningAmount** = 1
   - **MiningCollector.collectionWidth** = 2
   - **MiningCollector.collectionHeight** = 2
   - **BoxCollider2D.size** = (2, 2, 0)
   - **BoxCollider2D.isTrigger** = true（必须是 trigger）

### 3.4 连接引用

1. 选中 `MiningMachine` 父物体
2. 在 Inspector 中找到 `MiningCollector` 字段
3. 将 `CollectionArea` 子物体拖入该字段

### 3.5 添加 Sprite（可选）

1. 在 `Body` 子物体下创建 Sprite 子物体
2. 添加 `SpriteRenderer` 组件
3. 设置采矿机的图片

## 4. 工作流程

### 4.1 正常采集流程

```
1. 太空矿石漂浮到 CollectionArea 的 Collider 范围内
   ↓
2. 触发 MiningCollector.OnTriggerEnter2D()
   ↓
3. 检查电力：MiningCollector.HasPower()
   ├─ 无电力 → 跳过，不采集
   └─ 有电力 → 继续
       ↓
4. 调用 SpaceOre.Collect() 销毁矿石
   ↓
5. GameManager.AddResource(SpaceOre, miningAmount)
   ↓
6. 输出调试日志
```

### 4.2 电力检测流程

```
每帧 PowerManager.UpdatePower()
   ↓
计算总发电量和总需求量
   ↓
判断电力是否充足
   ↓
如果充足：
   PowerConsumer.SetPowerAvailable(true)
   ↓
   MiningCollector.HasPower() = true
   ↓
   可以采集矿石

如果不足：
   PowerConsumer.SetPowerAvailable(false)
   ↓
   MiningCollector.HasPower() = false
   ↓
   无法采集矿石
```

### 4.3 建筑受损流程

```
太空矿石碰撞到 Body 的 Collider
   ↓
触发 BuildingBase.OnTriggerEnter2D()（如果有实现）
   ↓
BuildingBase.TakeDamage(damage)
   ↓
currentHealth -= damage
   ↓
如果 currentHealth <= 0：
   BuildingBase.DestroyBuilding()
   ↓
   销毁建筑 GameObject
   ↓
   采矿机停止工作
```

## 6. 调试方法

### 6.1 启用调试日志

在 `MiningMachine` 和 `MiningCollector` 中设置：
- **enableDebug** = true

### 6.2 查看采集范围

1. 在 Unity Scene 视图中选中 `CollectionArea`
2. 看到绿色半透明框即为采集范围

### 6.3 常见日志信息

```
[MiningCollector] CollectionArea 采集矿石：+1, 当前总量：15
[MiningMachine] MiningMachine 无法工作：电力不足
[MiningCollector] CollectionArea 没有找到父物体上的 MiningMachine 组件
```

## 7. 常见问题

### Q1: 矿石不采集？
**检查**：
- CollectionArea 的 Collider 是否是 Trigger
- 电力是否充足（查看 PowerConsumer.isPowered）
- 矿石是否已经被标记为 IsCollected

### Q2: 采集后资源不增加？
**检查**：
- GameManager.Instance 是否存在
- MiningCollector.miningAmount 是否 > 0
- 查看 Console 是否有错误日志

### Q3: 电力检测不工作？
**检查**：
- MiningMachine 是否有 PowerConsumer 组件
- PowerConsumer.powerInput 是否设置正确
- PowerManager 是否在运行

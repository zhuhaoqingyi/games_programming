《异星太空工厂》2D俯视角工厂游戏 · 完整游戏设计文档

一、游戏核心定位（最重要）

游戏名称：异星太空工厂

游戏类型：2D俯视角 · 太空建造自动化工厂游戏（2.5D视觉）

核心玩法一句话：

玩家在陌生外星球从零开始，采矿 → 发电 → 建厂 → 自动化流水线 → 升级科技 → 建造太空基地，最终打造全自动星际工业帝国。

对标风格：异星工厂 + 戴森球计划（简化新手友好版）

视角：纯2D制作、固定俯视角2.5D视觉效果


---
二、游戏核心循环（主循环永远不变）

挖矿 → 耗电生产 → 物资入库 → 加工进阶材料 → 造更强机器 → 扩张基地 → 解锁太空科技

所有玩法围绕这个循环，简单、耐玩、无限扩张。


---
三、游戏世界观设定（纯太空场景，无任何行星地面）

玩家乘坐的星际远航运输船队遭遇宇宙乱流撞击，所有主飞船损毁报废，仅留存一座小型太空紧急避难仓侥幸完好，漂浮在荒芜死寂的深空区域。这片太空没有行星、没有陆地、没有大气，只有无尽黑暗宇宙和随处飘荡的天然资源。

这片深空区域资源储量极其丰富，遍布自然生成的太空漂浮矿石和废弃星际文明遗留的太空垃圾残骸，是唯一的生产原料来源；周边无任何外星文明、无生态环境，只有真空太空环境和持续漂浮刷新的各类基础物资。

玩家核心唯一生存与发展目标：

以一座小型太空紧急避难仓为初始根基，依托太空漂浮矿石、太空垃圾开采原料，一步步建造太空工业设施、搭建全自动太空流水线工厂，升级扩张太空基地规模，最终打造大型星际母舰，脱离这片荒芜深空，前往宜居星际航线。

游戏发展三大核心阶段（全程太空，无任何地面玩法）：

1. 避难生存阶段：依托初始紧急避难仓，搭建基础小型采集设备，手动+半自动开采太空漂浮矿石、太空垃圾，搭建简易供电系统，保障基础生存与初期生产运转。

2. 太空工业化阶段：建造全自动太空采矿机组、物流传输空间站、精炼加工平台，打造全自动化无人太空工厂，批量生产工业零件、高端电子材料，持续扩张太空基地模块。

3. 星际远航阶段：集齐所有高端航天核心材料，建造大型飞船组装空间站与强力推进器，打造专属星际远航母舰，完成远航启航目标，解锁后续深空探索新内容。


---
玩家飞船意外坠毁在一颗荒芜外星球。

星球资源丰富，但环境荒凉，没有文明。

玩家唯一目标：

从零手动挖矿 → 建造全自动工厂 → 重建飞船离开星球，飞向太空。

分三个阶段：

1. 地面阶段：基础采矿、发电、基础工厂

2. 工业化阶段：自动化传送带、精炼、零件加工

3. 太空阶段：造飞船、推进器、解锁太空建筑

五、所有建筑列表（暂定）

太空初始&基础核心建筑（开局必备）

- 太空紧急避难仓（初始自带）：玩家开局核心根基，自带基础小型储能模块、初始储物空间，无需建造，不可拆除，是所有工厂发展的起点

- 太空漂浮采矿平台：自动锁定周边飘荡太空矿石、太空垃圾，持续开采基础原料，运行需要消耗电力能源

- 太空核能发电模块：初期核心供电建筑，消耗少量太空矿石持续发电，为所有基础工业设备供能

- 太空太阳能发电阵列：后期无限清洁能源供电，依托深空恒星光照发电，无需消耗任何原料

- 太空仓储对接舱：专门存储开采的太空矿石、太空垃圾及各类加工成品零件，适配太空舱体物资密封存储逻辑

- 燃煤发电站：烧矿石发电，初期供电

- 太阳能发电站：后期无限电力

- 储物仓库：存矿石、材料、零件

工业加工建筑

- 熔炉精炼厂：矿石 → 金属锭

- 零件组装厂：金属锭 → 机械零件

- 高级加工厂：零件 → 电子元件、高科技材料

自动化物流建筑

- 传送带：自动运输物资

- 分拣器：分类不同材料

六、四大核心游戏系统（纯太空玩法适配优化）

1. 太空网格悬空放置系统（核心核心核心）

深空地图为无边太空网格空域，所有太空舱体、工业建筑、设备均悬空网格摆放，无地面依托。

功能：

- 点击UI按钮选择对应太空建筑模块

- 鼠标预览半透明悬空建筑效果，适配太空漂浮视觉

- 左键空域放置建筑、右键取消放置/拆除废弃舱体

- 建筑不可重叠放置，相邻舱体可自动生成对接连接逻辑

2. 太空电力能源系统（太空工厂命脉）

- 各类太空发电模块持续产生电力能源

- 采矿平台、加工舱、物流空间站所有设备运行均消耗电力

- 电力断开/能源不足，所有太空工业设备全部停止运转

- 电力充足状态下，所有工厂设备自动持续运行生产

3. 太空资源仓储与漂浮物流系统

- 太空仓储对接舱统一存储所有开采、加工物资

- 采矿平台开采的太空矿石、太空垃圾自动入库存储

- 各类太空加工舱自动从仓储舱调取所需基础原料

- 太空物流传输带对接各个舱体，自动转运各类太空工业物资

4. 太空工业生产加工合成系统

太空专属生产配方（贴合深空原料设定）：

- 太空漂浮矿石+太空垃圾 → 太空熔炉精炼舱 → 太空合金锭

- 太空合金锭 → 太空零件组装舱 → 星际机械零件

- 星际机械零件+高端合金 → 高级电子航天元件

- 所有航天高端材料最终用于建造星际远航母舰

七、玩家操作方式（简单易懂）

- WASD：移动地图视角

- 鼠标滚轮：缩放画面

- 左键：放置建筑

- 右键：取消放置 / 删除建筑

- UI按钮：选择要建造的机器

八、游戏胜利条件（通关目标）

集齐所有高级材料，在飞船组装平台建造完成星际飞船。

飞船建造完成 → 通关动画 → 进入太空新阶段。

# Space Builder Game - Development Plan Document
## Activity 1:
### Temporary Title: Space Builder
### One-Sentence Concept:
This is a space base building game where players place various buildings on a grid, collect resources, establish production chains, and ultimately construct an interstellar spaceship.

### Player Controls:
Players can freely explore the space scene, use the building UI to select and place structures on the grid—including mining, power generation, production, logistics, storage, and other facilities. They develop their base by managing resources and constructing production chains.

### Unity Format:
2D (Top-down perspective)

### Minimum Playable Version:
A complete building game. Players should be able to open the building UI, select structures, place buildings on the grid, and collect & consume resources.

### Core Systems:
Building placer with grid management system, dynamic camera, build mode toggle script on the character, resource manager, and various building scripts (mining, production, storage, etc.).

### GitHub:
<https://github.com/zhuhaoqingyi/games_programming>

### Biggest Risks:
Precise alignment of building placement and the grid system is somewhat difficult; balancing the resource production chain requires careful adjustment.

### Next Steps:
Improve the building placement and resource systems. (Complete basic building functions first)
